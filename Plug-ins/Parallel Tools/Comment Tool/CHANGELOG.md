# Changelog

## 0.24.0 (2026-11-17)

- New: **Font** and **Text size** in Settings, in styles and in Default Settings, so a style can carry its own text (a Client style larger than an Internal one). Blank and 0 leave Text > Format Text as before; a font or size set here wins over Format Text ([#2](https://github.com/itchyNZL/parallel-tools/issues/2)).
- New: **New get** in Preferences: new comments take the next number, or the lowest free one ([#1](https://github.com/itchyNZL/parallel-tools/issues/1)).
- Month names on the tag (9 Nov) are always English, whatever the computer's language ([#3](https://github.com/itchyNZL/parallel-tools/issues/3)).
- The plug-in object has new parameters (`NewNumbering`, `FontName`, `FontSize`): replace `Comment Tool.vso` as well as the code.
